# Coding Standards -- Joseph Perez

My coding standard for C#, SQL, testing, and documentation.

- [CODING-STANDARDS.md](CODING-STANDARDS.md) -- the full standard

The core rules are identical to the team standard I maintain on my current project, so there is one source of truth. The appendix holds personal additions (STIG notes, null handling, SQL habits, git, tools).

## Philosophy

1. Readability over cleverness
2. Explicit over implicit
3. Testable by default
4. Security first
5. Flexible within reason

Guidelines, not laws. Use judgment.
